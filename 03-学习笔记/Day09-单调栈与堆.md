## 一、今日 JS/TS 模板回顾

### 单调栈
```js
const stack = [];
const ans = Array(nums.length).fill(-1);

for (let i = 0; i < nums.length; i++) {
  while (stack.length && nums[stack.at(-1)] < nums[i]) {
    const idx = stack.pop();
    ans[idx] = nums[i];
  }
  stack.push(i);
}
```
