## 一、今日 JS/TS 模板回顾

### 回溯模板
```js
const ans = [];
const path = [];

function backtrack(start) {
  ans.push([...path]);

  for (let i = start; i < nums.length; i++) {
    path.push(nums[i]);
    backtrack(i + 1);
    path.pop();
  }
}

backtrack(0);
```
