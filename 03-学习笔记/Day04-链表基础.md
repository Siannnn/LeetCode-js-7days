## 一、今日 JS/TS 模板回顾

### TypeScript 辅助定义
```ts
class ListNode {
  val: number;
  next: ListNode | null;

  constructor(val = 0, next: ListNode | null = null) {
    this.val = val;
    this.next = next;
  }
}
```

### 虚拟头节点
```js
const dummy = new ListNode(0, head);
let cur = dummy;

while (cur.next) {
  cur = cur.next;
}

return dummy.next;
```
