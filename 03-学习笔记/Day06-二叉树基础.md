## 一、今日 JS/TS 模板回顾

### DFS 递归
```js
function dfs(root) {
  if (!root) return 0;
  const left = dfs(root.left);
  const right = dfs(root.right);
  return Math.max(left, right) + 1;
}
```

### BFS 队列（数组 + head 指针）
```js
const queue = [root];
let head = 0;

while (head < queue.length) {
  const node = queue[head++];
  if (node.left) queue.push(node.left);
  if (node.right) queue.push(node.right);
}
```
