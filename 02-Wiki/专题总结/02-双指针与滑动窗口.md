# 02 · 双指针与滑动窗口（JS/TS）

> **核心价值：** 用两个指针维护区间、窗口或链表位置，把暴力枚举降为 O(n)。

---

## 一、什么时候用

| 模式   | 场景          | 典型关键词         |
| ---- | ----------- | ------------- |
| 对撞指针 | 有序数组、两端收缩   | 两数之和、容器、接雨水   |
| 快慢指针 | 原地修改、链表环、中点 | 删除元素、移动零、环形链表 |
| 滑动窗口 | 连续子串/子数组    | 最长、最短、包含、不重复  |

---

## 二、对撞指针模板

```js
let left = 0;
let right = nums.length - 1;

while (left < right) {
  const sum = nums[left] + nums[right];
  if (sum === target) return [left, right];
  if (sum < target) left++;
  else right--;
}
```

---

## 三、快慢指针模板

```js
let slow = 0;

for (let fast = 0; fast < nums.length; fast++) {
  if (nums[fast] !== 0) {
    [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
    slow++;
  }
}
```

## 四、滑动窗口模板

```js
let left = 0;
const window = new Map();
let ans = 0;

for (let right = 0; right < s.length; right++) {
  const inChar = s[right];
  window.set(inChar, (window.get(inChar) ?? 0) + 1);

  while (/* 窗口不合法 */) {
    const outChar = s[left++];
    window.set(outChar, window.get(outChar) - 1);
    if (window.get(outChar) === 0) window.delete(outChar);
  }

  ans = Math.max(ans, right - left + 1);
}
```

### 固定 26 字母频次

```js
const freq = Array(26).fill(0);
for (const ch of s) freq[ch.charCodeAt(0) - 97]++;
```

---

## 五、JS 写法注意点

1. Hot 100 字符串通常是英文小写，`s[i]` 可以直接访问字符。
2. 如果题目涉及 Unicode 表情/复杂字符，JS 字符串索引和真实字符可能不一致；Hot 100 通常不用处理。
3. `right - left + 1` 是当前窗口长度。
4. 使用 `Map` 统计字符时，删除 0 次 key 可以让窗口状态更清晰。
5. 数组双指针交换可用 `[a, b] = [b, a]`。
