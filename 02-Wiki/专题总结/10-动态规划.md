# 10 · 动态规划（JS/TS）

> **核心价值：** 把大问题拆成重叠子问题，通过状态转移避免重复计算。

---

## 一、DP 五步法

1. 定义 `dp[i]` / `dp[i][j]` 的含义。
2. 写状态转移方程。
3. 初始化。
4. 确定遍历顺序。
5. 返回答案。

---

## 二、一维 DP

```js
const dp = Array(n + 1).fill(0);
dp[0] = 1;

for (let i = 1; i <= n; i++) {
  dp[i] = dp[i - 1];
}
```

---

## 三、二维 DP

```js
const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));

for (let i = 1; i <= m; i++) {
  for (let j = 1; j <= n; j++) {
    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
  }
}
```

---

## 四、最值型 DP

```js
const dp = Array(n).fill(Infinity);
dp[0] = 0;

for (let i = 1; i < n; i++) {
  dp[i] = Math.min(dp[i], dp[i - 1] + cost);
}
```

---

## 五、JS 写法注意点

1. 二维数组必须用 `Array.from` 初始化，避免共享行。
2. 无穷大用 `Infinity` / `-Infinity`。
3. 取最值用 `Math.max` / `Math.min`。
4. JS 没有 Python 负索引，`dp[-1]` 是 `undefined`，最后一项写 `dp[dp.length - 1]`。
5. 大数组不要用展开：`Math.max(...dp)` 可能栈溢出。
