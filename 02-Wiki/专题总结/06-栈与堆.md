# 06 · 栈与堆（JS/TS）

> **核心价值：** 栈解决后进先出和单调关系；堆解决动态最值。JS 没有内置堆，需要自定义。

---

## 一、栈

JS 数组天然适合当栈：

```js
const stack = [];

for (const item of items) {
  if (/* 需要入栈 */) stack.push(item);
  else {
    const top = stack.pop();
  }
}
```

## 二、单调栈

```js
function nextGreaterElement(nums) {
  const ans = Array(nums.length).fill(-1);
  const stack = [];

  for (let i = 0; i < nums.length; i++) {
    while (stack.length && nums[stack[stack.length - 1]] < nums[i]) {
      const idx = stack.pop();
      ans[idx] = nums[i];
    }
    stack.push(i);
  }

  return ans;
}
```

## 三、MinHeap 模板

```js
class MinHeap {
  constructor(compare = (a, b) => a - b) {
    this.heap = [];
    this.compare = compare;
  }

  size() { return this.heap.length; }
  peek() { return this.heap[0]; }

  push(value) {
    this.heap.push(value);
    this.bubbleUp(this.heap.length - 1);
  }

  pop() {
    if (this.heap.length === 0) return undefined;
    const top = this.heap[0];
    const last = this.heap.pop();
    if (this.heap.length > 0) {
      this.heap[0] = last;
      this.bubbleDown(0);
    }
    return top;
  }

  bubbleUp(index) {
    while (index > 0) {
      const parent = Math.floor((index - 1) / 2);
      if (this.compare(this.heap[parent], this.heap[index]) <= 0) break;
      [this.heap[parent], this.heap[index]] = [this.heap[index], this.heap[parent]];
      index = parent;
    }
  }

  bubbleDown(index) {
    const n = this.heap.length;
    while (true) {
      let smallest = index;
      const left = index * 2 + 1;
      const right = index * 2 + 2;

      if (left < n && this.compare(this.heap[left], this.heap[smallest]) < 0) smallest = left;
      if (right < n && this.compare(this.heap[right], this.heap[smallest]) < 0) smallest = right;
      if (smallest === index) break;

      [this.heap[index], this.heap[smallest]] = [this.heap[smallest], this.heap[index]];
      index = smallest;
    }
  }
}
```

### 大根堆

```js
const maxHeap = new MinHeap((a, b) => b - a);
```

## 四、JS 写法注意点

1. `push/pop` 是栈的 O(1) 均摊操作。
2. `shift()` 是 O(n)，不要用它做大队列模板。
3. JS 没有 Python 的 `heapq`，堆题要准备自定义类。
4. Top K 常用“小根堆维护 k 个最大值”。
5. 单调栈通常存索引，方便计算距离/宽度。
