# 09 · 二分查找（JS/TS）

> **核心价值：** 在有序性或单调性中用 O(log n) 找答案。

---

## 一、标准二分

```js
function binarySearch(nums, target) {
  let left = 0;
  let right = nums.length - 1;

  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
  }

  return -1;
}
```

---

## 二、lowerBound：第一个 >= target 的位置

```js
function lowerBound(nums, target) {
  let left = 0;
  let right = nums.length;

  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (nums[mid] < target) left = mid + 1;
    else right = mid;
  }

  return left;
}
```

## 四、JS 写法注意点

1. `mid` 用 `left + Math.floor((right - left) / 2)`。
2. JS 数字是双精度浮点，但 LeetCode 整数范围内通常安全。
3. 需要数字排序时必须写 `sort((a, b) => a - b)`。
4. 边界二分优先背 `left < right` + 左闭右开模板。
