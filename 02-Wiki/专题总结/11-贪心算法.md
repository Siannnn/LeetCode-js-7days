# 11 · 贪心算法（JS/TS）

> **核心价值：** 每一步做局部最优选择，并能证明局部最优可推出全局最优。

---

## 一、常见场景

| 场景 | 关键词 | 典型题 |
|------|--------|--------|
| 区间选择 | 重叠、合并、最少箭 | 合并区间 |
| 跳跃覆盖 | 最远可达 | 跳跃游戏 |
| 买卖股票 | 当前最低价/最大利润 | 买卖股票最佳时机 |
| 计数抵消 | 多数元素 | 摩尔投票 |

---

## 二、排序 + 贪心

```js
intervals.sort((a, b) => a[0] - b[0]);

const ans = [];
for (const cur of intervals) {
  if (!ans.length || ans[ans.length - 1][1] < cur[0]) {
    ans.push(cur);
  } else {
    ans[ans.length - 1][1] = Math.max(ans[ans.length - 1][1], cur[1]);
  }
}
```

---

## 三、最大覆盖

```js
let farthest = 0;
for (let i = 0; i < nums.length; i++) {
  if (i > farthest) return false;
  farthest = Math.max(farthest, i + nums[i]);
}
return true;
```

---

## 四、JS 写法注意点

1. 数字排序必须传比较函数。
2. 贪心题重点不是代码长，而是能解释为什么局部最优成立。
3. 更新最大/最小值用 `Math.max` / `Math.min`。
