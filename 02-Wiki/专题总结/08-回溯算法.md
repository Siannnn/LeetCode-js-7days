# 08 · 回溯算法（JS/TS）

> **核心价值：** 回溯是在决策树上 DFS：做选择 → 递归 → 撤销选择。

---

## 一、三要素

1. 路径：已经选择了什么。
2. 选择列表：当前还能选什么。
3. 结束条件：什么时候收集答案。

---

## 二、子集模板

```js
function subsets(nums) {
  const ans = [];
  const path = [];

  function backtrack(start) {
    ans.push([...path]);

    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);
      backtrack(i + 1);
      path.pop();
    }
  }

  backtrack(0);
  return ans;
}
```

---

## 三、排列模板

```js
function permute(nums) {
  const ans = [];
  const path = [];
  const used = Array(nums.length).fill(false);

  function backtrack() {
    if (path.length === nums.length) {
      ans.push([...path]);
      return;
    }

    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      used[i] = true;
      path.push(nums[i]);
      backtrack();
      path.pop();
      used[i] = false;
    }
  }

  backtrack();
  return ans;
}
```

---

## 四、JS 写法注意点

1. 收集路径时必须复制：`ans.push([...path])`。
2. 撤销选择用 `path.pop()`、`used[i] = false`。
3. 去重题通常先排序：`nums.sort((a, b) => a - b)`。
4. 不要频繁 `slice()` 创建大量数组，能用 `start` 下标就用下标。
