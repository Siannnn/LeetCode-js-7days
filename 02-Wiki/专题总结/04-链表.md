# 04 · 链表（JS/TS）

> **核心价值：** 用指针重连解决删除、反转、合并、找环等问题。

---

## 一、TypeScript 辅助定义

LeetCode JS 通常已提供 `ListNode`，这里用 TS 帮助理解类型：

```ts
class ListNode {
  val: number;
  next: ListNode | null;

  constructor(val = 0, next: ListNode | null = null) {
    this.val = val;
    this.next = next;
  }
}
```

---

## 二、虚拟头节点

```js
const dummy = new ListNode(0, head);
let cur = dummy;

while (cur.next) {
  cur = cur.next;
}

return dummy.next;
```

---

## 三、反转链表

```js
function reverseList(head) {
  let prev = null;
  let cur = head;

  while (cur) {
    const next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }

  return prev;
}
```

---

## 四、快慢指针

```js
let slow = head;
let fast = head;

while (fast && fast.next) {
  slow = slow.next;
  fast = fast.next.next;
}
```

---

## 五、JS 写法注意点

1. 空节点用 `null`，判断时用 `if (!head)`。
2. 改指针前先保存 `next`，避免链表断开后找不到后续节点。
3. 删除/插入题优先考虑 `dummy`，减少头节点特判。
4. 比较节点是否相同用引用相等：`nodeA === nodeB`。
