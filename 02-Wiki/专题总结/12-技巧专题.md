# 12 · 技巧专题（JS/TS）

> **核心价值：** 掌握位运算、摩尔投票、排序、原地技巧等高频小模板。

---

## 一、位运算

```js
const xor = a ^ b;
const and = a & b;
const or = a | b;
const shifted = x >>> 1;
```

### 只出现一次的数字

```js
let ans = 0;
for (const x of nums) ans ^= x;
return ans;
```

> JS 位运算会把数字转成 32 位有符号整数。Hot 100 常见位运算题通常可用，但要知道这个限制。

---

## 二、摩尔投票

```js
let candidate = null;
let count = 0;

for (const x of nums) {
  if (count === 0) candidate = x;
  count += x === candidate ? 1 : -1;
}

return candidate;
```

---

## 三、排序技巧

```js
nums.sort((a, b) => a - b);
nums.sort((a, b) => b - a);
```

---

## 四、JS 写法注意点

1. `sort()` 默认按字符串排序，数字题必须传比较函数。
2. 位运算按 32 位整数处理，不适合超过 32 位的大整数位操作。
3. 原地修改要看题目是否允许改变输入。
