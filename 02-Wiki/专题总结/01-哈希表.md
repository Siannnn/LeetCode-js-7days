# 01 · 哈希表（JS/TS）

> **核心价值：** 用 `Map` / `Set` 将查找、计数、分组从 O(n) 降到均摊 O(1)。

---

## 一、本质理解

哈希表的核心是 **空间换时间**：把已经见过的信息存起来，后续用 O(1) 均摊时间查询。

在 JavaScript 刷题中优先使用：

| 结构 | 适用场景 | 注意点 |
|------|----------|--------|
| `Map` | 值 → 下标、值 → 次数、分组 | key 不会被自动转字符串，适合数字/对象 key |
| `Set` | 去重、判断存在 | `set.has(x)` 判断是否存在 |
| 普通对象 `{}` | 字符串 key 的简单映射 | 数字 key 会被转成字符串，少用于算法模板 |
| 定长数组 | 字母频次、数字范围小 | 例如 `Array(26).fill(0)` |

---

## 二、核心模板

### 模板 1：两数之和（值 → 下标）

```js
function twoSum(nums, target) {
  const seen = new Map();

  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }

  return [];
}
```

### 模板 2：频次统计

```js
const freq = new Map();

for (const x of nums) {
  freq.set(x, (freq.get(x) ?? 0) + 1);
}
```

### 模板 3：字母异位词分组

```js
function groupAnagrams(strs) {
  const groups = new Map();

  for (const s of strs) {
    const key = s.split('').sort().join('#');
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(s);
  }

  return [...groups.values()];
}
```

### 模板 4：前缀和 + Map 计数

```js
function subarraySum(nums, k) {
  let prefix = 0;
  let ans = 0;
  const count = new Map([[0, 1]]);

  for (const x of nums) {
    prefix += x;
    ans += count.get(prefix - k) ?? 0;
    count.set(prefix, (count.get(prefix) ?? 0) + 1);
  }

  return ans;
}
```

---

## 三、JS 写法注意点

1. `map.get(key)` 可能返回 `undefined`，计数时用 `(map.get(key) ?? 0) + 1`。
2. `Map` 的 key 可以是数字、字符串、对象；普通对象的 key 会字符串化。
3. 分组时如果 key 不存在，先 `map.set(key, [])`，再 `map.get(key).push(value)`。
4. 字母频次可以用 `Array(26).fill(0)`，比 `Map` 更快，但只适合字符范围固定的题。
5. Python 的 `Counter/defaultdict` 在 JS 中通常用 `Map` 手动初始化实现。
