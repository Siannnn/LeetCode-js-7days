# 03 · 数组与矩阵（JS/TS）

> **核心价值：** 掌握 JS 数组初始化、原地修改、前缀和、矩阵遍历和边界处理。

---

## 一、JS 数组基础

```js
const arr = Array(n).fill(0);
const matrix = Array.from({ length: m }, () => Array(n).fill(0));
```

> 不要写 `Array(m).fill(Array(n).fill(0))`，所有行会引用同一个数组。

---

## 二、矩阵遍历

```js
for (let i = 0; i < matrix.length; i++) {
  for (let j = 0; j < matrix[0].length; j++) {
    const val = matrix[i][j];
  }
}
```

## 三、前缀和

```js
const prefix = Array(nums.length + 1).fill(0);

for (let i = 0; i < nums.length; i++) {
  prefix[i + 1] = prefix[i] + nums[i];
}

const sum = prefix[r + 1] - prefix[l];
```

## 四、原地修改

```js
let write = 0;
for (let read = 0; read < nums.length; read++) {
  if (/* nums[read] 需要保留 */) {
    nums[write++] = nums[read];
  }
}
```

---

## 五、JS 写法注意点

1. 数字排序必须写比较函数：`nums.sort((a, b) => a - b)`。
2. `slice()` 会复制数组，`splice()` 会原地修改数组。
3. `Math.max(...nums)` 对超大数组可能栈溢出，循环更稳。
4. 矩阵题先确认 `m = matrix.length`、`n = matrix[0].length`。
