# 1. 两数之和 (Easy)

> **专题归类：** [[02-Wiki/专题总结/01-哈希表]]  
> **LeetCode 链接：** https://leetcode.cn/problems/two-sum/  
> **默认语言：** JavaScript

---

## 题目描述

给定整数数组 `nums` 和整数 `target`，找出和为 `target` 的两个数，并返回它们的下标。题目保证有且仅有一组答案，同一个元素不能使用两次。

---

## 核心思路

用 `Map` 记录已经遍历过的数字及其下标。遍历到 `nums[i]` 时，先查 `target - nums[i]` 是否已经出现过；如果出现过，直接返回之前下标和当前下标。

这样天然避免“同一个元素用两次”，因为当前元素是在查询之后才写入 `Map`。

---

## JavaScript 代码

```js
function twoSum(nums, target) {
  const seen = new Map();

  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }

  return [];
}
```

---

## JS 写法注意点

- 用 `Map` 而不是普通对象，数字 key 不会被字符串化。
- `seen.has(need)` 要在 `seen.set(nums[i], i)` 之前执行，避免使用同一个元素。
- `seen.get(need)` 可能是 `0`，所以不能用 `if (seen.get(need))` 判断存在性，要用 `has`。

---

## 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(n)
