# 283. 移动零 (Easy)

> **专题归类：** [[02-Wiki/专题总结/02-双指针与滑动窗口]]  
> **LeetCode 链接：** https://leetcode.cn/problems/move-zeroes/  
> **默认语言：** JavaScript

---

## 核心思路

用快慢指针。`fast` 扫描所有元素，`slow` 指向下一个非零元素应该写入的位置。遇到非零元素就和 `slow` 位置交换。

---

## JavaScript 代码

```js
function moveZeroes(nums) {
  let slow = 0;

  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
      slow++;
    }
  }
}
```

---

## JS 写法注意点

- 题目要求原地修改，不需要 `return nums`。
- JS 交换可用解构赋值 `[a, b] = [b, a]`。
- 如果想减少无意义交换，可以在 `slow !== fast` 时才交换，但不是必要。

---

## 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(1)
