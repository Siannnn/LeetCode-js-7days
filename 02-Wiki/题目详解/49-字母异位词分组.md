# 49. 字母异位词分组 (Medium)

> **专题归类：** [[02-Wiki/专题总结/01-哈希表]]  
> **LeetCode 链接：** https://leetcode.cn/problems/group-anagrams/  
> **默认语言：** JavaScript

---

## 核心思路

字母异位词排序后结果相同，因此可以把“排序后的字符串”作为分组 key。用 `Map<string, string[]>` 收集同一组单词。

---

## JavaScript 代码：排序 key

```js
function groupAnagrams(strs) {
  const groups = new Map();

  for (const s of strs) {
    const key = s.split('').sort().join('');
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(s);
  }

  return [...groups.values()];
}
```

---

## JavaScript 代码：计数 key

当字符串很长时，可以用 26 位频次数组作为 key：

```js
function groupAnagrams(strs) {
  const groups = new Map();

  for (const s of strs) {
    const count = Array(26).fill(0);
    for (const ch of s) count[ch.charCodeAt(0) - 97]++;

    const key = count.join('#');
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(s);
  }

  return [...groups.values()];
}
```

---

## JS 写法注意点

- Python 的 `defaultdict(list)` 在 JS 中写成 `Map` + 手动初始化。
- 数组不能直接作为 `Map` 的内容相等 key；`[1,2]` 和另一个 `[1,2]` 是不同引用，所以要 `join('#')` 序列化。
- 字符串排序：`s.split('').sort().join('')`。

---

## 复杂度

- 排序 key：O(n · k log k)，k 是单词平均长度
- 计数 key：O(n · k)
- 空间复杂度：O(n · k)
