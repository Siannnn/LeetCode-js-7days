# 15. 三数之和 (Medium)

> **专题归类：** [[02-Wiki/专题总结/02-双指针与滑动窗口]]  
> **LeetCode 链接：** https://leetcode.cn/problems/3sum/  
> **默认语言：** JavaScript

---

## 核心思路

先排序。固定第一个数 `nums[i]`，再用左右指针在 `i + 1..n-1` 中找两数之和等于 `-nums[i]`。难点是去重。

---

## JavaScript 代码

```js
function threeSum(nums) {
  nums.sort((a, b) => a - b);
  const ans = [];

  for (let i = 0; i < nums.length - 2; i++) {
    if (i > 0 && nums[i] === nums[i - 1]) continue;
    if (nums[i] > 0) break;

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];

      if (sum === 0) {
        ans.push([nums[i], nums[left], nums[right]]);
        left++;
        right--;

        while (left < right && nums[left] === nums[left - 1]) left++;
        while (left < right && nums[right] === nums[right + 1]) right--;
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }

  return ans;
}
```

---

## JS 写法注意点

- 数字排序必须写 `nums.sort((a, b) => a - b)`，否则默认按字符串排序。
- 去重有三处：固定的 `i` 去重、找到答案后 `left` 去重、`right` 去重。
- 返回的是数值组合，不是下标。

---

## 复杂度

- 时间复杂度：O(n²)
- 空间复杂度：O(log n) 到 O(n)，取决于排序实现；不计结果数组为 O(1) 额外空间
