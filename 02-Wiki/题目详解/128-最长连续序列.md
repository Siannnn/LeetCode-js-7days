# 128. 最长连续序列 (Medium)

> **专题归类：** [[02-Wiki/专题总结/01-哈希表]]  
> **LeetCode 链接：** https://leetcode.cn/problems/longest-consecutive-sequence/  
> **默认语言：** JavaScript

---

## 核心思路

用 `Set` 去重并支持 O(1) 查询。只从“连续序列起点”开始扩展：如果 `num - 1` 不存在，`num` 才是起点。

这样每个数最多被访问常数次，总时间 O(n)。

---

## JavaScript 代码

```js
function longestConsecutive(nums) {
  const set = new Set(nums);
  let ans = 0;

  for (const num of set) {
    if (set.has(num - 1)) continue;

    let cur = num;
    let len = 1;
    while (set.has(cur + 1)) {
      cur++;
      len++;
    }

    ans = Math.max(ans, len);
  }

  return ans;
}
```

---

## JS 写法注意点

- `new Set(nums)` 可完成去重。
- 关键优化是 `if (set.has(num - 1)) continue;`，否则会退化成重复扩展。
- 遍历 `Set` 用 `for (const num of set)`。

---

## 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(n)
