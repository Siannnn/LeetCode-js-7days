# 42. 接雨水 (Hard)

> **专题归类：** [[02-Wiki/专题总结/02-双指针与滑动窗口]] · [[02-Wiki/专题总结/06-栈与堆]]  
> **LeetCode 链接：** https://leetcode.cn/problems/trapping-rain-water/  
> **默认语言：** JavaScript

---

## 思路一：双指针

维护左右两侧最高柱子 `leftMax` 和 `rightMax`。每次移动较低的一侧，因为较低侧能接多少水只取决于它自己这一侧的最大值。

```js
function trap(height) {
  let left = 0;
  let right = height.length - 1;
  let leftMax = 0;
  let rightMax = 0;
  let ans = 0;

  while (left < right) {
    leftMax = Math.max(leftMax, height[left]);
    rightMax = Math.max(rightMax, height[right]);

    if (leftMax < rightMax) {
      ans += leftMax - height[left];
      left++;
    } else {
      ans += rightMax - height[right];
      right--;
    }
  }

  return ans;
}
```

## 思路二：单调栈

栈中维护递减高度的下标。当前高度比栈顶高时，说明形成了右边界，可以结算中间凹槽的水量。

```js
function trap(height) {
  const stack = [];
  let ans = 0;

  for (let i = 0; i < height.length; i++) {
    while (stack.length && height[i] > height[stack[stack.length - 1]]) {
      const bottom = stack.pop();
      if (!stack.length) break;

      const left = stack[stack.length - 1];
      const width = i - left - 1;
      const boundedHeight = Math.min(height[left], height[i]) - height[bottom];
      ans += width * boundedHeight;
    }

    stack.push(i);
  }

  return ans;
}
```

---

## JS 写法注意点

- 双指针版空间 O(1)，更适合面试首选。
- 单调栈版要存下标，不要只存高度，因为需要计算宽度。
- 访问栈顶用 `stack[stack.length - 1]`。

---

## 复杂度

- 双指针：时间 O(n)，空间 O(1)
- 单调栈：时间 O(n)，空间 O(n)
