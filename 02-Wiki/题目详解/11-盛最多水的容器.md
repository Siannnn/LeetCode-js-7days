# 11. 盛最多水的容器 (Medium)

> **专题归类：** [[02-Wiki/专题总结/02-双指针与滑动窗口]]  
> **LeetCode 链接：** https://leetcode.cn/problems/container-with-most-water/  
> **默认语言：** JavaScript

---

## 核心思路

左右指针从两端开始，面积由较短的边决定。每次移动较短边，才有机会在宽度变小的情况下提高高度。

---

## JavaScript 代码

```js
function maxArea(height) {
  let left = 0;
  let right = height.length - 1;
  let ans = 0;

  while (left < right) {
    const h = Math.min(height[left], height[right]);
    const width = right - left;
    ans = Math.max(ans, h * width);

    if (height[left] < height[right]) left++;
    else right--;
  }

  return ans;
}
```

---

## JS 写法注意点

- 数组下标从 0 开始，宽度是 `right - left`。
- 移动较短边，不移动较长边。
- 面积计算用 `Math.min` 和 `Math.max`。

---

## 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(1)
